## Proyecto Actual: *ecommerce_usb*
Estamos trabajando en el proyecto **ecommerce_usb**, una plataforma de comercio electrónico basada en micro‑servicios:
- **Backend principal**: API RESTful construida con Spring Boot, exponiendo endpoints para gestión de productos, pedidos y usuarios.
- **Persistencia**: PostgreSQL como almacén de datos relacional, con esquemas versionados mediante Flyway.
- **Seguridad**: Autenticación JWT y autorización basada en roles.
- **Arquitectura**: Desglosada en servicios independientes (catálogo, carrito, pagos) comunicados vía RabbitMQ.
- **Infraestructura**: Desplegada en contenedores Docker, orquestada con Docker‑Compose para entornos de desarrollo y Kubernetes para producción.
- **Observabilidad**: Métricas con Micrometer, trazas con OpenTelemetry.

El objetivo del proyecto es proporcionar una solución robusta, extensible y segura para tiendas online, sirviendo también como caso de estudio práctico para los estudiantes de la asignatura de desarrollo backend.
